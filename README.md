# B0Xaz-Universal

Project structure scaffold.

## Repository layout

- `src/Core` — shared runtime primitives
- `src/Services` — application services
- `src/Types` — shared type definitions
- `src/Constants` — project constants
- `src/Plugins` — plugin and game-module boundaries
- `src/UI` — interface structure
- `src/Utilities` — reusable utilities
- `configs` — default and preset configuration files
